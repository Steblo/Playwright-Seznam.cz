# Playwright‑Seznam.cz

Automatizované UI testy pro Seznam.cz pomocí Playwrightu a C# (.NET 9).  
Projekt obsahuje MSTest testy seřazené pomocí `Priority` a CI pipeline běžící na GitHub Actions (Ubuntu), která generuje TRX výsledky jako artefakty.
Součástí projektu je také Playwright tracing a screenshots, které se ukládají pouze při selhání testu.

---

## 🚀 Technologie

- .NET **9.0**
- Playwright for .NET
- MSTest V2 + Priority
- GitHub Actions CI (Ubuntu)
- TRX test artefakty
- Playwright Trace & Screenshots (jen při selhání)
